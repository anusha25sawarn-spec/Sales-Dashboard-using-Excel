
📊 Sales Dashboard Analysis Using Microsoft Excel

 Introduction

The Sales Dashboard Analysis is an interactive data analysis project developed using **Microsoft Excel** to analyze sales performance and uncover meaningful business insights from raw sales data.

The dashboard provides a consolidated view of key sales metrics such as **total sales, profit, quantity sold, product performance, regional performance, and sales trends over time**.

The primary objective of this project is to demonstrate how Excel can be used to transform raw business data into an interactive and easy-to-understand dashboard that supports **data-driven decision-making**.
